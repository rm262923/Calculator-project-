# Simple Calculator

This is a basic calculator I made in Python for my Python Essentials course project.

## What it does

It asks the user to pick an operation (add, subtract, multiply, divide), then asks for two numbers, and shows the result. After that it asks if you want to calculate again, so you can keep using it without restarting the program.

## How to run it

```
python calculator.py
```

## How it works (in simple words)

- I used a `while` loop so the program keeps running until the user types "no".
- I used `if / elif / else` to check which operation the user picked.
- I used `float()` on the inputs so it works with decimal numbers, not just whole numbers.
- I added a check for division by zero, because dividing by zero gives an error in Python.

## Concepts used

- Variables
- while loop
if / elif / else statements
Taking user input
Basic error handling (division by zero)
